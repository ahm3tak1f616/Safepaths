# Security Policy

## Supported Versions

Only the latest release targeting Minecraft 1.20.1 on Forge receives active updates and bug/security fixes on this branch.

| Mod Version | Minecraft Version | Supported          |
| ----------- | ----------------- | ------------------ |
| 2.0.1       | 1.20.1            | :white_check_mark: |
| 2.0.0 and older | 1.20.1        | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or serious exploit in Safepaths:

1. **Do not create a public issue.**
2. Report the vulnerability privately via [GitHub Private Vulnerability Reporting](https://github.com/ahm3tak1f616/Safepaths/security/advisories/new) or contact the author via your GitHub profile.
3. Please include detailed steps to reproduce the issue (such as world seed, steps, or logs).

You will receive an acknowledgment within 48–72 hours, and verified issues will be patched in the next minor release.
