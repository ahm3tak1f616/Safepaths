# Security policy

The latest release is maintained for Minecraft 1.21.1 NeoForge and Minecraft 1.20.1 Forge. Older releases do not receive fixes independently.

Report security vulnerabilities through [private vulnerability reporting](https://github.com/ahm3tak1f616/Safepaths/security/advisories/new). Include affected versions, reproduction steps, and relevant logs. Use public issues for ordinary bugs that do not expose an exploit.
